Windows 11

02Versions and what has changed

Windows version numbers look like 24H2 or 25H2: the number is the year, and the H tells you which half of the year it was released in. To check your own version: open File Explorer, right-click This PC, choose Properties, and look under Windows specifications.

Correction from class

In the lecture I said 24H2 was the current version — the demonstration machine was built on it. The current release is 25H2, which shipped September 30, 2025, and 24H2 stops receiving security updates on October 13, 2026. There is also a 26H1 release, which breaks the "always H2" pattern. If your own machine is on 24H2, run Windows Update before mid-October.

Two changes the textbook doesn't reflect

  • WordPad has been removed as of 24H2. It used to create RTF (Rich Text Format) files. Microsoft's position now is: use Notepad for plain text, use Word for formatted documents.
  • The Action Center was renamed. Your textbook says Win + A opens the Action Center; it now opens Quick Settings. Notifications and the calendar moved to Win + N.

Home vs. Pro

Windows 11 Home targets personal use; Pro targets businesses and schools. Both encrypt the data written to your drive by default, using a key unique to your machine. Pro adds administrative management on top — so a company can recover an employee's data if that employee forgets their password.

Security fundamentals

03Sign-in, PINs, and disk encryption

The key idea

A PIN is safer than your Microsoft account password, because a PIN only works on one device. If someone watches you type your Microsoft password, they can now reach your email, your OneDrive, and everything else tied to that account — from anywhere. If someone learns your PIN, it is useless without your physical laptop, and you fix the problem by changing the PIN on that one machine.

The same logic makes biometrics attractive. A fingerprint sensor or face unlock (Windows Hello) stores the biometric data locally on the device, not in the cloud.

Why a stolen laptop no longer means stolen data

It used to be that you could pull a hard drive out of one computer, connect it to another, and read everything on it. That no longer works, because the drive's contents are encrypted with a key that lives on the machine.

Windows 11 requires a TPM — Trusted Platform Module — which is a small dedicated chip whose job is to hold those encryption keys. When your PC boots, Windows must satisfy the TPM before the TPM will hand over the key. If it can't, the key is never released and the data stays unreadable. The key is a 256-bit value, which is large enough that brute-forcing it is not a realistic attack.

This is also why, on a company laptop, IT can recover your data when you forget your password: BitLocker Management gives administrators a recovery path that individual users don't have. As a home user you should know where your recovery key is stored before you need it — I'll post instructions.

Correction from class

I described the TPM as requiring "a password." More precisely, the TPM releases the key based on measurements it takes of the system during startup — if the boot environment has been tampered with, the measurements don't match and the key stays locked. The practical conclusion is the same.

Windows 11

05Arranging windows and desktops

Snap layouts

Drag a window to the top or side of the screen and Windows offers preset arrangements — two side by side, three across, and so on. Once two windows are snapped, drag the divider between them to give one more space than the other.

Virtual desktops

Press Win + Tab to see task view. At the bottom you can create additional desktops with the + button, rename one by right-clicking it, or close one with the X. The point is separation: one desktop for coursework, another for personal browsing, and you switch between them without closing anything.

The taskbar

A small underline beneath an icon means that application is currently running. Right-click an icon to pin it, which keeps it on the taskbar even after you close the app, or unpin it to remove it. Pinned icons can be dragged into whatever order you like.

Right-clicking a taskbar icon may also show a jump list — recent files or locations for that application, so you can reopen something in one click.

Windows 11

06File Explorer

When you sign in to Windows, you get a folder under Users named for your login. That is where your own files belong.

Quick Access

Right-click any folder and choose Pin to Quick Access to keep it in the left-hand sidebar. Pin a folder for this course and you will reach it in one click every time.

Search scope matters

Searching from the C: drive searches the entire machine, which can take a very long time. Navigate into the specific folder first and search from there — dramatically faster, because it only looks in one place.

Turn on file extensions

By default, Windows hides file extensions. Turn them on: View → (down arrow) → Show → File name extensions.

Why this is a security setting, not a cosmetic one

With extensions hidden, a file that displays as syllabus.pdf might actually be syllabus.pdf.exe — a program, not a document. You would have no way to tell before double-clicking it. With extensions visible, the disguise stops working. Turn them on and leave them on.

Extensions worth recognizing:

ExtensionWhat it isRisk
.exeExecutable programHigh — never run one from an email
.cmd, .batCommand scriptsHigh
.ps1PowerShell scriptHigh
.zipCompressed folderDepends on contents
.pdfPortable documentLower, but not zero — PDF readers have had vulnerabilities that a malicious PDF can exploit
.ini, .logSettings and log files — plain textLow

Be cautious with attachments even from people you know: their account may be compromised, or the sender address may be spoofed.

Windows 11

07OneDrive and files on demand

OneDrive folders show a small icon next to each file telling you where it actually lives. A cloud icon means the file is stored online and is not taking up space on your machine; double-clicking downloads it. A checkmark means a local copy exists.

When your disk runs low, OneDrive can quietly remove local copies of files it has safely backed up. To prevent that for a specific file, right-click it and choose Always keep on this device. Do this before travel, or before any situation where you might be offline.

Every MDC student has a OneDrive account through the college. Use it.

Turn on AutoSave for anything that matters

AutoSave in Word works in conjunction with OneDrive — save the document into your OneDrive folder and AutoSave becomes available. It also gives you version history, so you can go back to an earlier draft. Every semester someone loses a paper they had been working on for a week. Don't be that person.

Windows 11

08Keeping the machine healthy

  • Windows Security / Defender is built in and enabled by default. It scans programs before they run and can run a full system scan on demand. Its limitation is important: it recognizes known threats, and new malicious software appears constantly — which is exactly why keeping it updated is not optional.
  • Windows Update — check it regularly. Security updates close the vulnerabilities that attacks depend on.
  • Installed apps (Add/Remove Programs) — uninstall what you don't use. Sort by size to find what's eating your disk.
  • Install software from the Microsoft Store where you can. Free download sites are a common malware vector.
  • Default apps — this is where you decide which program opens PDFs, which browser handles links, and so on.

How a real attack chains together

Suppose your PDFs open in Edge, and you're behind on updates, so you're running a version of Edge with a known bug. Someone emails you a PDF crafted to trigger that bug. You open it. Now code runs on your machine, and the attacker installs ransomware (which encrypts your files and demands payment) or a keylogger (which records everything you type, including banking passwords).

Notice that every link in that chain was preventable with an update.

Turn on two-factor authentication

For anything high-value — bank, email, school account — enable 2FA so that a stolen password alone isn't enough. Use a text code or, better, an authenticator app.

Modern authenticator prompts show a two-digit number you must type in rather than a simple Approve button. That change exists because attackers were flooding people with approval requests until someone tapped Approve by accident. And if an approval prompt appears when you are not logging in, that is a live signal your password is compromised — change it immediately.

Ransomware note: paying is no guarantee of recovery, and if attackers got in once they can get in again. Backups and updates are the real defense.

Microsoft Word

09Chapters 1–2: the parts that trip people up

Formatting marks — turn them on and leave them on

On the Home tab of the ribbon, click the ¶ button (a pilcrow). This reveals characters that are normally invisible:

MarkWhat it means
¶End of a paragraph — created every time you press Enter
· (raised dot)A space
↵ (arrow)A line break — created by Shift + Enter
→A tab character
° (small circle)A non-breaking space

Keep these visible for the whole course. Most "why is this document doing that?" problems turn out to be an invisible character you couldn't see.

The most important idea in this lecture

A paragraph in Word is not what you think it is. It is simply "everything between two ¶ marks" — even if that's a single line, or a single word. Press Enter and you have started a new paragraph. Press Shift + Enter and you have started a new line inside the same paragraph.

This is why alignment behaves the way it does. Click in a three-line address where each line ends with Enter, then hit Center, and only the one line you clicked in centers — because each line is its own paragraph. Use Shift + Enter between those lines instead, and all three center together, because now they are one paragraph.

Character formatting vs. paragraph formatting

Ribbon buttons fall into two groups, and the difference explains most unexpected results:

TypeApplies toExamples
Character formattingOnly the text you have selectedBold, italic, underline, font, font size, color
Paragraph formattingThe whole paragraph your cursor is in — no selection neededLeft / Center / Right / Justify, line spacing, indents, bullets

So to bold three words you must select those three words. To center a paragraph you only need to click inside it. To center three separate paragraphs you must select all three.

Justify stretches spacing so every line reaches both margins — the look used in books and newspapers. It has little visible effect on short lines like an address.

Non-breaking space

Press Ctrl + Shift + Space. This glues two words together so Word will never split them across a line break. Use it for things that should never be separated: 9 AM, Dr. Smith, Figure 3, 100 MB. Without it, you can end up with "9" at the end of one line and "AM" at the start of the next.

The Editor: spelling and grammar

  • Open Editor from the Home tab to review spelling and grammar together.
  • If the same word is misspelled repeatedly, use Change All rather than fixing each one.
  • Ignore Once skips this instance; Ignore All skips it for this document.
  • Add to Dictionary is permanent and global — that word will never be flagged again in any document, and undoing it means editing your custom dictionary by hand. Use it sparingly.

Ignoring an error does not fix it. Close and reopen the document and the flags come back, because nothing was changed.

Paste options

Click the small arrow beneath the Paste button (or right-click where you're pasting) for four choices:

OptionResult
Keep Source FormattingText arrives looking exactly as it did where you copied it
Merge FormattingText adopts the formatting of the document you're pasting into
Keep Text OnlyStrips all formatting — the safest option when pasting from a website
PicturePastes the content as an image rather than editable text

Find and Replace

Two options matter far more than students expect:

  • Find whole words only. Without it, replacing "cat" with "dog" also mangles "catalog" and "concatenate". This single checkbox is the difference between a clean replacement and a damaged document.
  • Match case. With case matching handled properly, replacing "CAT" produces "DOG" and replacing "cat" produces "dog" — Word preserves the capitalization pattern.

Find and Replace can also search for special, non-printable characters — blank lines, tabs, paragraph marks — which is how you clean up a document full of stray empty paragraphs.

Change Case

The Aa button on the Home tab converts the case of selected text without retyping it: Sentence case, lowercase, UPPERCASE, Capitalize Each Word, and tOGGLE cASE. For a title, Capitalize Each Word is normally what you want.

Correction from class

I mentioned that two spaces after a period is generally acceptable. Current style guides — APA, Chicago, and MLA — all call for one space between sentences, and Word's Editor flags two by default. Since SimNet grades against Word's own checker, use one.

10Ribbon vocabulary SimNet uses

SimNet grades you on clicking the right thing, and it describes that thing using Microsoft's own interface vocabulary. Most points lost on these assignments are lost to terminology, not to skill. Learn these words.

TermWhat SimNet means
RibbonThe entire command bar across the top of the window
TabA named section of the ribbon — Home, Insert, Layout, References
GroupA labeled cluster within a tab — the Font group, the Paragraph group
ButtonA single clickable command, such as Bold
Button arrowThe small arrow attached to a button that opens its extra choices
GalleryA grid of visual choices — Styles, Themes, Table Styles
More buttonThe arrow that expands a gallery to show everything in it
Dialog launcherThe tiny diagonal arrow in a group's bottom-right corner that opens the full dialog box
Practical tip

When a SimNet task says "click the dialog launcher in the Paragraph group," it is naming an exact location. Read the instruction as a map: which tab → which group → which control.
