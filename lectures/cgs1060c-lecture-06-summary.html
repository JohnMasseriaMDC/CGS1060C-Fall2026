Artificial intelligence

02You have been using AI for years

AI isn't new. Computer scientists were writing about neural networks — software loosely modeled on how brain cells connect — as far back as the 1960s. Science fiction got there even earlier; the 1987 film RoboCop imagined a machine making life-and-death judgments, and the joke in that film is that the prototype had a bug.

What you've already been using:

Everyday thingWhat the AI is doing
Spam filteringStatistical analysis of which words appear in junk mail. Clicking "report spam" feeds the model a new example.
Siri and AlexaSpeech recognition trained on enormous amounts of recorded audio, plus rules for interpreting commands.
Face unlock and photo taggingComputer vision that learned facial features from examples rather than from rules someone wrote.
Netflix, YouTube, Amazon recommendationsFinding people whose history resembles yours and suggesting what they liked.
Self-driving featuresLive object detection — drawing boxes around pedestrians, cars, and signs, many times a second.

One underlying point worth keeping: a great deal of AI is statistics. A spam filter takes in words and outputs a probability. Above a threshold it's spam, below it isn't.

Artificial intelligence

03Machine learning: two kinds

The idea that separates machine learning from ordinary programming

Normally, to make a computer do something, you write the rules. To sort numbers, you write a sorting algorithm.

But nobody can write the rules for "is this a cat?" You'd be listing ear shapes forever. Machine learning instead learns from examples — show it enough labeled pictures and it works out the distinguishing features itself.

Supervised learningUnsupervised learning
Training dataLabeled — you tell it the answer for each exampleUnlabeled — you just supply the data
What it learnsTo predict the label for new inputTo find clusters of similar items
ExamplesImage recognition, speech recognition, spam filtering, AI-text detectionGrouping medical measurements, customer segmentation, finding patterns nobody specified

With unsupervised learning the computer doesn't know what its clusters mean — a human looks at the groups and says "these are all cancerous cells" or "these are all pictures of cats." The machine found the grouping; the person supplied the name.

The question I asked in class

If you wanted to build a model that detects AI-written text, would you use supervised or unsupervised learning?

Supervised. Feed it a large pile of human-written text labeled "human," and a large pile of AI-written text labeled "AI." The trained model then takes new text and returns a probability.

How the pieces nest

Artificial intelligence is the whole field. Inside it sits machine learning (learning from examples). Inside that sits deep learning (machine learning using multi-layer neural networks). And inside that sits generative AI — the newest layer, and the one everyone is talking about.

Inside an artificial neuron

In your brain, nerve cells connect at synapses and carry continuously varying signals. An artificial neuron is the mathematical echo of that: several numeric inputs, each multiplied by a weight, all summed. If the total passes an activation threshold, the neuron fires a value onward.

Stack thousands of these into hidden layers between input and output, and you have a neural network. Pixels go in one end; "cat" or "not a cat" comes out the other. Note the honest caveat: a biological neuron and an artificial one are genuinely different things. The analogy is useful, not literal.

Artificial intelligence

04How generative AI actually works

ChatGPT, Microsoft Copilot, Claude, and Gemini are all generative AI: trained on vast quantities of text, and fundamentally engaged in predicting the next word.

The breakthrough came from a 2017 Google research paper, Attention Is All You Need, which described the architecture these models use. Ironically, OpenAI was the company that first brought it to the public.

What "predicting the next word" means in practice

Give the model "The cat sat on the…" and it looks up the probability of every possible next word. Mat might be most likely, then floor, couch, bed, roof. It picks one, appends it, and repeats — using everything written so far as the input for the next step.

A setting called temperature controls how adventurous that choice is. Low temperature picks the most probable word, producing safe and predictable text. Higher temperature reaches further down the list, which is where creative or surprising output comes from — and also where errors come from.

Parameters, and why the models keep improving

A model's parameters are the numbers it learned during training — each one a single value. Models have gone from millions to billions to trillions, and more parameters has consistently meant more capability.

That's also why these systems need so much hardware. A model with billions of parameters must hold all those numbers in memory. A well-equipped personal computer can run a smaller model locally; the frontier models run on clusters of machines in data centers.

This connects to something you may have noticed in shops: computer memory has become more expensive. Manufacturers are prioritizing the high-speed memory AI data centers want, which squeezes supply for ordinary laptops and devices.

Why GPUs

A GPU — graphics processing unit — was built for video games, drawing millions of pixels at once. It's good at doing enormous numbers of simple calculations in parallel.

It turns out that a neural network is, mathematically, a stack of matrices, and running one is mostly matrix multiplication — exactly the kind of work that parallelizes. So the hardware built for gamers became the hardware that runs AI, and NVIDIA became one of the world's most valuable companies.

05Tokens and vectors

Models don't work with words exactly. Text is split into tokens — whole words, pieces of words, or punctuation. "Unbelievable!" might become un, believ, able, !.

Each token is then represented as a vector: a list of numbers describing a direction and a distance in space. In two dimensions a vector is just a point with an x and a y. These vectors have hundreds or thousands of dimensions, which nobody can picture — but the mathematics works regardless, and you can subtract one from another to get a third.

The result that makes this click

Take the vector for king, subtract man, add woman. You land very close to queen.

The same direction connects father to mother, and son to daughter. The model was never taught about gender. It arrived at a consistent geometric relationship purely from how those words are used in text.

Related words sit near each other too — royalty words cluster together, family words cluster together. This is why these models appear to handle meaning, even though they're manipulating numbers.

Artificial intelligence

06Hallucination, and why it sounds so convincing

Definition

A hallucination is when a model states something confidently that simply isn't true. It hasn't lied — it has no concept of true and false. It generated the most plausible-sounding continuation, and plausible isn't the same as correct.

The classic example: a 60 Minutes segment where a model was asked who Lesley Stahl is and answered that she's a journalist at NBC News. She works for CBS. In the model's internal representation "CBS News," "NBC News," and "CNN" all sit close together as plausible continuations of "is a journalist who works for…" — so it picked a neighbor.

Why hallucinations are dangerous rather than merely annoying: the wrong answer is written just as fluently as the right one. There is no stammer, no hedge, no visible uncertainty. Fluency is not evidence of accuracy.

The other failure mode: flattery

These models are tuned to be agreeable. Describe a business idea and you'll often be told it's excellent and you're insightful — regardless of whether it is. People have made real decisions on the strength of that encouragement.

If you want a genuine assessment, ask for the objections. "What are the three strongest arguments against this?" gets you something far more useful than "what do you think of my idea?"

Artificial intelligence

07RAG — and why NotebookLM is different

A plain generative model answers from its training, which is a problem for accuracy. By the time billions of documents have been compressed into a set of parameters, every trace of where a fact came from is gone. The model knows something but has no idea how it knows it — so it cannot cite anything, and can't tell you when it's guessing.

Retrieval Augmented Generation (RAG)

RAG bolts a search step onto the front. When you ask a question:

  1. The system searches for relevant documents — web pages, PDFs, your own uploaded files.
  2. It feeds the actual text of those documents into the model along with your question.
  3. The model answers from that text, and can point at the source.

This is why a tool that shows you citations must be doing retrieval. A model answering from training alone cannot produce a real reference — it has nothing to point at.

Ask a modern assistant about Lesley Stahl today and it searches first, reads her Wikipedia page and the CBS site, and answers from that. Far less likely to hallucinate. (With one caveat worth keeping: retrieval is only as good as the sources retrieved, and anyone can edit a Wikipedia page.)

NotebookLM

NotebookLM is Google's RAG tool, and it's the subject of an upcoming assignment. You supply the source documents, and it answers only from them. Ask something the sources don't cover and it tells you it can't find an answer rather than inventing one.

That constraint is the whole point. For studying from your own notes, readings, and slides, it's a much safer tool than a general chatbot. Demonstration comes first thing next week.

Using AI well

08Six ingredients of a strong prompt

The quality of what you get out is largely determined by what you put in. Compare "write me an email" with the version built from all six ingredients.

IngredientExample
1. Be specific"Write a 150-word welcome email" — not "write an email"
2. Give context"…for new clients of a small day spa in Doral"
3. Assign a persona"Act as an experienced spa manager"
4. Specify the format"Output a table with three columns headed Service, Duration, Price"
5. Specify the tone"Plain English, friendly, short sentences — write it the way you'd talk to a coworker"
6. Iterate"Make the second description shorter." "Add a Spanish version." "Give me two more options with a more upbeat tone."

The sixth matters most and gets used least. Your first response is a draft, not an answer. Push back on it.

How memory and context actually work

Each new chat generally starts fresh. Some tools keep a long-term memory of facts you explicitly ask them to remember, but by default a new conversation doesn't know about your old ones.

Within one conversation, every follow-up re-sends the entire history — your first prompt, the model's answer, your second prompt, and so on. The conversation gets more expensive to process as it grows, which is why paid plans have usage limits over a rolling window, and why a very long thread eventually slows down. When you change topic, start a new chat.

09Good jobs and bad jobs for AI

Good fitBad fit
Brainstorming ideasFacts you can't verify yourself

Explaining a concept a different way when the textbook isn't landingAnything involving private or proprietary data
Generating practice questions to study fromWork you're going to submit as your own thinking

The practice-questions use is genuinely underrated. Paste in a chapter, ask for twenty questions on it, and you have a study tool built from the actual material.

Never paste private or proprietary data

If you're working, don't put your employer's confidential material into a public AI tool. A real example from the news: a mathematician at NYU was using an AI service to work on a famous unsolved problem. He hadn't switched off the setting that permits prompts to be used for training — so when the company later announced progress on that same problem, it could not rule out that his own work had fed into the model.

Most paid tiers let you exclude your prompts from training. Find that setting before you put anything sensitive in.

About AI-detection tools

Software claiming to identify AI-written text exists, and it works the way described in section 3 — supervised learning on labeled examples. It returns a probability, not a verdict.

These tools are unreliable, and they flag writing by non-native English speakers at notably higher rates. I'll state my own policy plainly in class next week so nobody is guessing. In the meantime, the standard for this course is unchanged: you need to be the one doing the thinking, and you're responsible for what you submit.

Corrections

10Fixing things I said in earlier lectures

Virus vs. worm — the distinction is how it spreads

A virus attaches to a file or program and needs you to run it. The classic example is Melissa (1999), a macro hidden in a Word document that ran when you opened the file.

A worm needs nothing from you at all. Being connected to a network is enough. It arrives over the wire and infects you.

A Trojan is malware disguised as something you want, so you install it yourself. Modern malware usually combines all three behaviors.

SQL Slammer, 2003 — a worm in the wild

A single small network message, sent to a vulnerable database service, triggered a buffer overflow: the receiving software mishandled the message and ended up executing part of it as program code. That code then sent copies to random addresses as fast as the machine could manage.

The detail that makes it a teaching story: at a company I worked for, a firewall blocked it from the internet entirely — and it got in anyway, on an employee's laptop that had been infected on a hotel network and then plugged into the office. Firewall logs let us trace the first outbound attempt back to patient zero. And a patch had been available for months.

Same lesson from WannaCry in 2017: Microsoft released the fix on March 14, and the worm hit on May 12 — 59 days later, striking only machines that hadn't applied it. A worm doesn't beat the patch; it beats the people who didn't install it.

A zero-day

A zero-day is a vulnerability with no patch available yet — the vendor has had zero days to fix it. These are valuable enough that well-funded attackers, including nation states, invest heavily in finding them and keeping them secret. Which is the same lesson again: install updates promptly. An occasional patch causes problems; an unpatched system causes worse ones.

Microsoft Excel

11Chapter 5: pivot tables

A pivot table summarizes a large table of raw records without altering the original data. The demo used spa transactions: date, month, service, location, staff member, amount.

Prerequisite

Your first row must be column headings, and every column needs one. Those headings become the field names, so a sheet without them produces a useless pivot table.

Building one

  1. Click any cell inside the data.
  2. Insert → PivotTable, and place it on a new worksheet. (Recommended PivotTables offers guesses, but building it yourself gives you control.)
  3. Drag fields into the four areas of the field pane.
AreaWhat it doesIn the demo
RowsOne row per distinct valueService — one row per treatment type
ValuesThe number being summarizedAmount — total revenue per service
ColumnsSplits across the pageMonth — revenue by service and month
FiltersNarrows the whole table to selected valuesLocation — view one branch at a time
Sum is only the default

Click the field in the Values area → Value Field Settings → and switch to Average, Count, Max, Min, and others. Total revenue per service answers one question; average revenue per service answers a different and often more interesting one.

The real power is in rearranging. Move Location from Columns to Filters and the same data answers a different question. Swap Month and Location and it answers another. Nothing you do to a pivot table changes the underlying data — experiment freely.

Microsoft Excel

12What-if data tables and Goal Seek

Both tools build on last week's PMT function: =PMT(annual_rate/12, years*12, loan_amount).

One-variable data table

What happens to my payment at 4%, 5%, 6%, 7%, or 8%?

  1. List the rates you want to test down a column.
  2. In the cell one row above and one column right of that list, put a reference to the formula result.
  3. Select the whole block, including the header cell and the list of rates.
  4. Data → What-If Analysis → Data Table.
  5. Leave Row input cell empty. Set Column input cell to the cell your rates should be fed into — the interest-rate cell in the original calculation.

Excel substitutes each rate into the real formula and reports the resulting payment.

Two-variable data table

What happens across five interest rates and four loan terms at once? Same idea, but rates run down the left column and terms run across the top row. Now you fill in both: Row input cell = the number-of-years cell, Column input cell = the interest-rate cell. You get a complete grid.

Formatting tip from the demo

Data-table results don't inherit formatting, so they appear as raw numbers. Apply a custom number format to the result range — dollar sign, thousands separator, two decimals, red for negatives — before you generate the table.

Goal Seek — working backwards

The question Goal Seek answers

A data table asks "what happens if I change this?" Goal Seek asks the reverse: "what would this input need to be for the answer to come out at X?"

Data → What-If Analysis → Goal Seek. Three boxes: Set cell (the formula result), To value (your target), By changing cell (the one input Excel may adjust).

Worked example: a $25,000 car at 6% over 5 years gives a payment of about $483. I can only afford $400. Setting the target to −400 (payments are negative) and changing the loan amount returns about $20,690 — so I'd need roughly a $4,300 down payment.

Two things the demo showed that are worth copying:

  • The target cell must contain a formula, not a typed value. There's nothing for Goal Seek to solve otherwise.
  • Pick the right variable. Changing the interest rate to hit $400 returned a negative rate — a mathematically valid answer to a meaningless question. Goal Seek will happily give you nonsense if you aim it at the wrong input.

Behind the scenes it's just iterating: adjust, recalculate, compare to target, repeat until close.
