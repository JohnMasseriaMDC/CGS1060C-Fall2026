File management

02How files are organized

Every file has an address, and the structure that gives it one is called a directory tree. It's called a tree because each folder is a node, and the items beneath it are branches. Folders can contain folders can contain folders; a file is always the end of a branch, because nothing lives inside a file.

TermMeaning
Directory / folderThe same thing, two names. A container for files and other folders.
Subdirectory / subfolderA folder inside another folder.
Parent directoryThe folder one level up.
Root directoryThe top of the tree. C:\ on Windows, / on Mac and Linux.
Home directoryYour personal folder, named after your login, holding Documents, Downloads, and so on.
PathThe full address of a file, written out folder by folder.

The slashes differ. Windows separates folders with a backslash (C:\Users\John\Documents). Mac and Linux use a forward slash (/Users/John/Documents). That's a surface difference, but it's the one you'll notice first.

A directory doesn't hold your data — it holds information about the files inside it: names, sizes, dates, where the actual content sits on disk. That's why you can't open a folder and read it as a document; you run a command that reads the folder's records and formats them for you.

Where the "Downloads" file went

When you download something in a browser, it almost always lands in your Downloads folder. Nine times out of ten, the file you "can't find" is there. It's also worth clearing out periodically — most people's Downloads folder holds years of accumulated junk.

A little history

Mac OS is built on Unix, an operating system created at AT&T Bell Labs in the early 1970s. The name was a joke: the big mainframe system of the day was called Multics — multiplexed — so the smaller, simpler system its authors wrote became Unics, then Unix. Linux is a Unix-like system written by Linus Torvalds, and he still approves the changes that go into it. macOS and iOS descend genuinely from Unix; Android is built on the Linux kernel, so it is Unix-like rather than Unix-derived. Windows comes from a separate lineage, which is why its conventions differ.

03Saving, and which format to choose

Ctrl + S saves — on Windows and on Mac (where it's Cmd + S). The first time you save a new document, Word asks where to put it and what format to use.

FormatUse it whenWhat you lose
.docxDefault. Normal Word documents.Nothing
.docSending to someone on a very old version of WordNewer formatting features may not survive
.pdfSending a document that must look identical everywhereEasy editing — that's the point
Web page (.htm)Publishing content to a websiteLayout fidelity
Plain text (.txt)You need only the wordsAll formatting — fonts, sizes, alignment, images
Why PDF exists

Before PDF, a document written on one kind of computer frequently looked wrong — or wouldn't open at all — on another. Adobe's answer was a format that renders identically everywhere, readable with free software. That is still the reason to use it: you should never require someone to buy Microsoft Word just to read what you sent them. Both Chrome and Edge display PDFs directly, with no reader to install.

The mysterious ~$ file

Open a Word document and look in its folder: you'll find a second file with the same name prefixed by ~$. That's a temporary working file Word creates while the document is open, used partly for crash recovery. Close the document and it disappears on its own. Don't delete it by hand while Word is running.

Save As, and versions

Save overwrites the existing file — the previous content is gone unless you have a backup. Save As creates a new file and leaves the original alone, which is the manual way to keep a version history (report-v1.docx, report-v2.docx). The automatic way is OneDrive, below.

File management

04Compression, and file types

The core distinction

Lossless compression finds repetition and stores it more efficiently. Unzip the file and you get back byte for byte exactly what you started with. Nothing is discarded.

Lossy compression permanently throws away detail chosen to be hard for human senses to notice. The file gets far smaller, and you can never recover what was removed.

CategoryExtensionsNotes
Documents.docx .pdf .txt .rtf—
Images.jpg .png .gifJPEG is lossy; PNG and GIF are lossless
Audio.mp3 .wavMP3 is lossy; WAV is uncompressed
Video.mp4 .mov .avi—
Archives.zip .rarLossless. Windows and Mac both zip and unzip natively now
Executables.exe .cmd .bat .ps1Programs. Never run one that arrived by email

PNG vs. JPEG — the practical rule

JPEG discards visual detail the eye is poor at noticing, which makes photographs dramatically smaller. PNG keeps everything, and compresses by finding repeated patterns.

Refining what I said in class

I said PNG files are much larger than JPEG. That's true for photographs — and false for screenshots, logos, diagrams, and anything with large areas of flat color, where PNG is frequently smaller as well as lossless. The rule to remember: photographs → JPEG. Screenshots and graphics → PNG. Also use PNG when you need transparency, which JPEG cannot do.

Audio, and why it mattered

Sound is analog. Digitizing it means sampling the wave many times a second and storing the numbers; play the numbers back and you reconstruct the wave. A .wav file stores those samples uncompressed, so a CD-quality track runs roughly 30–50 MB. MP3 compresses the same track to around 3–5 MB — about ten to one — by discarding detail most listeners can't hear. Not identical to the original, but close enough that it changed the industry: MP3 is what made a pocket-sized music player possible, which is what made the iPod possible.

RAW, for photographers

A camera's RAW format keeps the full sensor data with no compression loss, so editing in Photoshop doesn't degrade the image. Export to JPEG at the end, once.

File management

05What happens when you delete

Deleting a file normally does not destroy it. It moves to the Recycle Bin (Windows) or Trash (Mac), and you can right-click and Restore it. The bin's icon changes to show it has contents.

SituationRecoverable?
Normal delete on your hard driveYes — it's in the Recycle Bin
Shift + Delete on WindowsNo — bypasses the bin entirely
Deleting from a USB / thumb driveNo — these have no recycle bin
Deleting from a network driveUsually no
Deleting from OneDriveYes — OneDrive has its own recycle bin
A file too large to fit in the binNo — Windows warns you first

Avoid Shift + Delete as a habit. The recycle bin costs you nothing and has saved everyone at least once.

Copy, cut, move

  • Ctrl + C then Ctrl + V — copy a file, leaving the original in place.
  • Ctrl + X then Ctrl + V — move it.
  • Or drag it. Watch the tooltip while you drag — Windows tells you whether it's about to copy or move before you let go.
Protecting your work

06Cloud storage and backup

The three big consumer services are OneDrive (Microsoft), Google Drive, and iCloud (Apple). Free tiers are typically around 5 GB, which fills up fast if you take photos; paid tiers run from about $2/month for 100 GB to roughly $10/month for a terabyte shared across a family.

Through Miami Dade College you already have a Microsoft account tied to your school email, with OneDrive attached. Use it for coursework.

Version history is the feature that saves you

Save a file in OneDrive and it keeps every previous version. Open the file's location, click the three dots, choose Version history, and restore any earlier copy. I demonstrated this on a file I've revised 164 times since 2024.

This is also why Word's AutoSave only switches on for documents stored in OneDrive — AutoSave depends on version history to be safe. Without it, autosaving would just overwrite your work faster.

Why version history beats ransomware

Ransomware encrypts everything it can reach and demands payment for the key. If it reaches your OneDrive folder it will encrypt those files too — but the previous versions are still there, so you can roll back. On a computer with no cloud sync and no backup, your only option is paying, and paying is not a guarantee.

A real backup plan

  1. Important documents and photos go in the cloud. Preferably more than one service; they're cheap and they fail independently.
  2. Buy an external USB drive and run a full backup to it. Buy from a manufacturer with a reputation — a suspiciously cheap high-capacity drive is a bad bet when the whole point is reliability.
  3. Disconnect the drive between backups. A backup drive permanently attached to an infected computer gets encrypted along with everything else. Unplug it and put it in a drawer.
  4. Repeat weekly. The first backup copies everything and takes a while; after that, incremental backups copy only what changed, so they're fast.
A South Florida consideration

Hurricanes and house fires destroy the drive in your drawer as effectively as they destroy the computer. Irreplaceable documents and photographs should exist in at least one place outside your house — which is what cloud storage is for. People who lost family photos in Hurricane Andrew had no digital copy anywhere.

Digital identity

07Privacy and your data

GDPR

The General Data Protection Regulation is European law, but its reach is global: if your company has customers in the EU, you must comply regardless of where you are based. Penalties run up to 4% of worldwide annual revenue, which is large enough that essentially every multinational complies. It is a major reason websites now ask you about cookies, and why companies must disclose breaches.

Cambridge Analytica

Around the 2016 election, a company called Cambridge Analytica put a personality quiz on Facebook. Facebook's data-sharing rules at the time let the quiz collect information not just about the person taking it, but about all of their friends. Most people whose data was harvested never touched the quiz.

The lesson isn't "don't take quizzes." It's that your privacy depends partly on other people's choices, and that connecting an app to a social account grants access that persists until you revoke it. Go into Facebook's settings and remove apps you no longer use.

Metadata in your photos

Metadata means data about data. Every photo your phone takes carries hidden fields: the date, the time, the camera settings — and, because your phone has GPS, the exact location where it was taken. Post a photo taken at home and you may have published your address. Both iOS and Android can strip location data when sharing; find that setting and use it.

How the ad business actually works

Facebook, Google, and Amazon are free or cheap because knowing about you is the product. Search for something on Google and an ad for it follows you onto YouTube, because they're the same company. Look at coffee on Amazon and the coffee ads arrive that evening. Feeds are tuned to keep you scrolling, because time on the app is inventory to sell.

Companies can also infer things you never told them. In a well-documented case, Target identified pregnant customers from shifts in ordinary shopping patterns — and started mailing baby coupons before some of them had told their families.

DNA testing sites

Consumer genetic testing is not covered by HIPAA. Those databases have been used by police to identify suspects — often not by finding the person, but by finding a cousin and working backwards. The Golden State Killer was identified this way in 2018. Whatever you think about that outcome, notice the mechanism: a relative's decision can expose you, and you never consented to anything.

VPNs and HTTPS

On a coffee-shop network, a site using HTTPS already encrypts the contents of what you send, so an eavesdropper can't read it. What still leaks is DNS — the lookup that turns a site name into an address — which reveals which sites you're visiting even if not what you do there. A VPN encrypts that too, so the network owner sees nothing useful.

Never click through a certificate warning

If your browser says a site's security certificate is invalid, do not click the button to proceed. You may have mistyped the address, or the site may be misconfigured, or someone may be intercepting your connection. Check the URL, try a different browser, but don't bypass the warning.

Deepfakes and AI-generated media

Telling a real video from a generated one is already difficult and getting worse. The defensive habit is not visual — it's checking the source. Where did this come from? Does anyone else report it? Does the account have a history?

Digital identity

08Copyright, licensing, and open source

Copyright protects the expression of an idea, not the idea itself. You can copyright your photograph of a sunset. Nobody can copyright sunsets. Copyright is automatic when you create something, and it expires eventually — the original Steamboat Willie Mickey Mouse entered the public domain on January 1, 2024. Anything in the public domain is free for anyone to use.

What this means in practice: using someone else's software code verbatim, or ripping a DVD and posting it, is infringement. If you need an image for something you're publishing, you either license it or use something that is already free to use.

Correction from class — this one matters

I described Creative Commons as material with no copyright over it. That isn't right, and the difference will cost you points. CC works are copyrighted — the licence grants specific permissions in advance, and most CC licences require you to credit the creator. Some also forbid commercial use, or require that your own work carry the same licence. Read which licence applies before you use the image, and attribute it.

The DMCA

The Digital Millennium Copyright Act (1998) is why YouTube and Facebook can exist. It shields a platform from liability for what users upload, provided the platform gives copyright owners a way to report infringement and removes it promptly. That's the takedown-notice system.

Open source

Open source software publishes its source code so anyone can read it. Linux is the best-known example. Licences differ in what they demand of you — some require only attribution, some require that anything you build on top also be open. "No licence stated" does not mean free to use; legally it means all rights reserved.

There's a long-running argument about whether open source is more secure. One side: more people can read the code, so bugs get found — and many projects pay bug bounties to the white hat researchers who report them. The other side: proprietary code is harder to study, so it's harder to attack. Both arguments have merit.

Don't use pirated software

Beyond the legal exposure: whoever cracked that software is not doing it as a public service. Pirated installers are one of the most reliable ways to get malware. You have free access to Microsoft Office through the college — use it.

A story against myself

I was reading an article and clicked an ad headlined something like "the 20 best bone-conducting headphones." The top-rated product looked reasonably priced, so I bought it — and then bought a second at 50% off. It turned out the company that makes the product had written the "review." The headphones are not good.

Two things to take from that. A ranked list can be an advertisement, and the tell — an immediate upsell after purchase — was right in front of me. And because I paid by credit card, I can still get my money back if the return is refused.

The same skepticism applies to messages. A WhatsApp message from your boss stranded overseas asking for money is a well-worn scam, and it works because the account may genuinely be compromised. Verify through a channel you chose, not the one that contacted you.

10Chapters 3–5: what we covered

Mac users

SimNet simulates Word on Windows. Word for Mac has real differences in menu placement and some shortcuts. The simulations will still work — they run in your browser — but if you practice in Word on your own Mac, expect the odd thing to sit somewhere else.

Tab stops and the ruler

Tab stops are set on the ruler at the top of the document. The small marker at the ruler's left end cycles through the tab types when you click it; then click on the ruler to place one.

Tab typeEffect
LeftText begins at the stop and runs right
CenterText centers on the stop
RightText ends at the stop
DecimalNumbers align on their decimal point — use this for columns of currency
BarDraws a vertical line at that position
The mistake everyone makes

Tab stops apply only to the paragraphs you have selected. Click in one line and set a right tab, and only that line moves. To format a whole table of tabbed text, select all of it first, then set the stop.

Leaders are the dots that run from a chapter title to its page number in a table of contents. Double-click the tab stop on the ruler to open the Tabs dialog, and choose a leader: none, dots, dashes, or a solid line.

Page breaks

To push content to the next page, do not press Enter repeatedly. That looks right until you add a sentence above it, and then the whole document shifts. Use Insert → Page Break, which stays put no matter what you edit above it.

Headers, footers, and page numbers

Double-click the top or bottom margin to enter the header or footer area. From there, Page Number inserts a number that updates itself as the document grows. Headers and footers repeat on every page automatically — put them in once.

Images: wrapping and alt text

Right-click an image and choose Wrap Text to control how the text relates to it: in line with text, square, tight, behind text, in front of text. "Behind text" and "in front of text" let images and words overlap.

Alt text is an accessibility feature

Alternative text describes an image for someone using a screen reader, who cannot see it. Right-click the image and add alt text — Word can suggest a description using AI, which you should then read and correct, since Word labels its own suggestions as possibly inaccurate. If an image is purely decorative and carries no information, mark it as decorative instead so readers skip it.

Citations and bibliographies

The References tab will build your citations for you. Insert a citation, choose the source type (website, book, journal), fill in the fields once, and Word formats it. Insert a bibliography or works-cited page, and when you add more sources later, click Update Citations and Bibliography and it regenerates itself.

The two common styles are APA (American Psychological Association) and MLA (Modern Language Association). Word handles both, plus Chicago and others. Your instructor in any given course tells you which to use.

Still the single most useful habit

Turn on the pilcrow (¶) button on the Home tab and leave it on. Seeing the paragraph marks, spaces, tabs, and line breaks explains almost every "why is Word doing this?" moment you will have this semester.
