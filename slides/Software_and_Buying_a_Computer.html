SYSTEM VS. APPLICATION SOFTWARE
Software comes in layers
System software
Runs the computer itself. You rarely notice it until something breaks.
Application software
Does your tasks: writing, browsing, music, games.
Drivers
Small programs that let the OS talk to a printer, graphics card, or webcam.
CGS 1060C · Software and Buying a Computer
THE OPERATING SYSTEM
Five jobs the OS does all day
1 · Manages hardware
Shares CPU time and RAM among everything that's running.
2 · Runs apps
Starts programs and decides which apps the device can run.
3 · Organizes files
Folders, drives, OneDrive or iCloud sync.
4 · Protects you
Sign-in, user accounts, security updates.
5 · Talks to you
The interface: windows, touch, voice.
The OS is also called the platform: it decides which apps you can use.

SECURITY HABIT · INSTALLING SOFTWARE
Where you download from matters more than what you download
✓ Safer sources
  • Microsoft Store, Mac App Store, Google Play, Apple App Store
  • The developer's official website
  • Your school's software page
✗ Risky sources
  • Download sites with several big "Download" buttons
  • "Free" copies of paid software
  • Pop-ups saying you need a driver or update
Read every installer screen. Uncheck extra toolbars or "offers." An administrator prompt means the program can change your system.

ACTIVITY · FIVE MINUTES
App audit
  1. Open your installed apps list (paths on the right).
  2. Sort by size. Find your biggest app.
  3. Find one app you haven't opened in three months.
  4. Post a category in Teams chat, like "biggest: a game, 60 GB."
Where to look
Windows: Settings › Apps › Installed apps Mac: System Settings › General › Storage › Applications (i) Phone: Settings › General › iPhone Storage, or Settings › Storage
Nothing personal needed. Don't uninstall anything from your PC maker or any driver unless you know what it does.

CGS 1060C · Software and Buying a Computer
SOFTWARE CONSIDERATIONS
Check the software before you buy the hardware
Compatible?
Does the software run on that OS and chip? Chromebooks run web apps only. Most Windows apps now run on Arm laptops; a few older ones don't.
Free through school?
Many programs are free or discounted for students. Check MDC's student software page first.
Training and updates?
Some programs have a steep learning curve. Check how long the OS and apps will keep getting updates.
Remember Windows 10: computers that couldn't run Windows 11 stopped getting free security updates in October 2025.
