TYPES OF COMPUTERS
Three families, and the lines are blurring
Personal
Desktop, all-in-one, laptop, 2-in-1, tablet, smartphone. One person at a time.
Hidden
Embedded computers inside cars, thermostats, smart TVs, and watches, running a small real-time OS.
Shared
Servers share files, websites, and apps. Mainframes run huge transaction loads. Supercomputers run science.

CLOCK SPEED, CORES, AND THREADS
What the numbers on a processor mean
Clock speed
Measured in gigahertz. 3.8 GHz = 3.8 billion clock cycles per second. Running faster than rated is overclocking: more heat, voided warranty.
Cores
Each core is a complete processor. More cores let the computer work on more tasks at the same time.
Threads
Hyperthreading lets one core juggle two streams of instructions, filling its idle moments.
GHz alone doesn't decide speed. Cores, cache, chip design, and 64-bit word size all matter. Compare benchmarks, not just GHz.

HIDDEN GEM
Why does a 1 TB drive show about 931 GB? Drive makers count 1 TB as 1,000,000,000,000 bytes. Windows divides by 1,024 × 1,024 × 1,024, so the same bytes display as 931.
Text codes
ASCII covers 128 English characters. Unicode covers about 150,000: Spanish ñ, Chinese, emoji. Most of the web uses UTF-8 (1–4 bytes per character).

WIRELESS CONNECTIONS
Radio waves for most things, light for remotes
Wi-Fi
Wireless network, standard 802.11. 2.4 GHz reaches farther; 5 and 6 GHz are faster. A public access point is a hotspot.
Bluetooth
Short range, about 30 feet. Earbuds, keyboards, mice, car audio. Passes through walls.
NFC
Near-field communication: a few centimeters. Tap to pay, transit cards, pairing.
Infrared
Light, not radio. Needs line of sight, so it can't pass through walls. TV remotes.
