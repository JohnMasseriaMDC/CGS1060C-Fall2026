Entering and editing
Ready mode replaces; Edit mode changes part
Ready mode
Select the cell and start typing. Everything in the cell is replaced when you press Enter or Tab.
Use it to replace a whole value.
Edit mode
Double-click the cell (or press F2). A cursor appears inside; arrow keys move within the text.
Use it to fix a typo in a long entry or a formula.
The left end of the status bar tells you which mode you're in: Ready, Enter, or Edit.
Trap: Typing a number over a formula replaces the formula. The cell looks right today and never updates again.

Common confusion
Three kinds of “delete” do three different things
Delete key
Removes the contents. The cell, its formatting, and any conditional formatting stay.
Fastest; leaves the look behind
Clear button
Home › Editing › Clear: Clear Formats, Clear Contents, or Clear All. The cell stays.
You choose what goes
Delete button
Home › Cells › Delete removes the cell itself. Neighbors shift up or left to fill the gap.
Changes the layout
Trap: Delete a cell that a formula uses and the formula shows #REF!. It doesn't pick up whatever slides into that spot.
Insert works the same way in reverse: a single cell or a row-shaped range shifts cells down; a column-shaped range shifts them right.

Hidden gem
Two settings that quietly stick around
Find and Replace formatting
A format you set next to Find what stays set for your next search. If Find suddenly finds nothing, click Options and look for a format.
Fix: Format button arrow › Clear Find Format.
Print area
Set Print Area prints only that range, every time, until you clear it.
Fix: Page Layout › Print Area › Clear Print Area. Check File › Print before printing.
When Excel does something you didn't ask for, look for a setting you forgot you set.
